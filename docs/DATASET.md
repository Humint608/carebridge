# 학습 데이터셋 요약 — 케어브릿지

실제 수급자의 메모를 수집하지 않고 합성 사례만 사용한다는 본 아이디어 솔루션 제안자의 질의답변서를 따라, **직접 구축한 합성 데이터**로 학습·검증했습니다. 실제 수급자의 기록, 이름, 연락처는 포함하지 않습니다.

## 1. 구성

| 세트 | 규모 | 용도 | 파일 |
|---|---|---|---|
| 학습 절 | 5,624개 | 모델 학습 | `data/clauses_train.jsonl` |
| 미학습 문형 검증 절 | 1,182개 | 처음 보는 문장 틀에서 일반화 측정 | `data/clauses_heldout.jsonl` |
| 합성 메모 | 300건 (필드 1,228개) | 절 분리를 포함한 엔드투엔드 스트레스 테스트 | `data/memos_synth.jsonl` |
| 현장형 자유서술 | 25건 (필드 67개) | 템플릿과 무관하게 손으로 쓴 개발 검증용 | `data/freetext_test.json` |
| 블라인드 자유서술 | 15건 (필드 36개) | 개발 완료 후 1회만 평가 | `data/blind_test.json` |

언어별 학습 절은 베트남어 1,780 · 한국어 1,302 · 인도네시아어 1,004 · 우즈베크어 984 · 네팔어 554개입니다.

## 2. 라벨 체계 (제안자 답변의 기록 항목 기준)

| 기록 항목 | 세부값 |
|---|---|
| 방문 시점 VISIT | 시각을 규칙으로 추출(5개 언어, 데바나가리 숫자 포함) |
| 제공한 지원 SUPPORT | 목욕·세면 / 이동·보행 / 옷 갈아입기 / 식사 보조 / 환경 정리 / 체위 변경 |
| 식사 MEAL | 전량 / 대부분 / 절반 / 소량 / 안 함 / 양 미기재 × 아침·점심·저녁·간식·시점 미기재 |
| 수면 SLEEP | 잘 잠 / 잘 못 잠 / 자주 깸 |
| 불편감 표현 DISCOMFORT | 무릎 / 허리 / 머리 / 배 / 다리 / 어깨 / 가슴 / 부위 미특정 |
| 복약 관련 관찰 MEDICATION | 복용 관찰 / **미확인** / 거부 |
| 배변·배뇨 EXCRETION | 있음 / 없음·적음 / 묽은 변 |
| 정서 MOOD | 좋음 / 기운 없음 / 불안·화냄 |
| 특이사항 EVENT | 넘어짐 / 넘어질 뻔함 |

'식사 관찰'(MEAL)과 '식사 보조 제공'(SUPPORT·MEAL_ASSIST)은 서로 다른 라벨로 분리했습니다. 제안자 답변("식사 관찰은 식사 지원을 수행했다는 사실과 같지 않으며")을 반영한 것입니다.

## 3. 구축 방법

1. **문형 템플릿**: 언어·항목·세부값마다 3~4개 문장 틀을 둡니다. 호칭({s})·식사 시점({t})·신체 부위({p})·시각({h}) 슬롯을 조합합니다. (`data/templates.py`)
2. **핵심표현 사전**: 문장 틀과 무관하게 세부값을 결정하는 짧은 표현입니다(예: 절반 / một nửa / आधा / setengah / yarmini).
3. **증강**
   - 베트남어 성조부호 제거: 현장 스마트폰 입력 습관 반영 (예: `ba an het com trua`)
   - 한국어 현장 축약체: 드셨습니다 → 드심, 도와드렸습니다 → 도와드림
   - 소문자화
4. **미학습 문형 분리**: 각 문형 목록의 마지막 문장 틀은 학습에서 빼고 검증에만 씁니다.
5. **자유서술·블라인드**: 템플릿을 쓰지 않고 손으로 썼습니다. 개인정보(이름·전화번호)를 일부 넣어 마스킹도 함께 검증합니다.

## 4. 예시

```json
{"lang": "ne", "text": "हजुरआमाले दिउँसोको खाना आधा खानुभयो", "cls": "MEAL", "label": "HALF", "meal_time": "LUNCH"}
{"lang": "vi", "text": "ba an het com trua", "cls": "MEAL", "label": "ALL", "meal_time": "LUNCH"}
{"lang": "uz", "text": "Dori ichganini tekshira olmadim", "cls": "MEDICATION", "label": "NOT_CONFIRMED"}
{"lang": "id", "text": "Saya menyuapi Nenek", "cls": "SUPPORT", "label": "MEAL_ASSIST"}
{"lang": "ko", "text": "두 시간 간격으로 체위 바꿔드림", "cls": "SUPPORT", "label": "REPOSITION"}
```

실제 엔진 출력 40건은 `eval/SAMPLE_OUTPUTS.md`와 `eval/sample_outputs.json`에 있습니다.

## 5. 고도화 방향성

- **언어 표현 고도화**: 기관 실증 단계에서 원어민 교육생·강사의 검수를 거쳐 각 언어의 현장 표현을 보강하고, 언어별 세부값 정확도를 높입니다.
- **문형 확장**: 교육기관 실증에서 수집되는 연습 메모(동의 기반)를 단계적으로 반영해 실제 현장의 다양한 문장 틀을 학습 데이터에 축적합니다.
- **항목 체계 확장**: 기관별 기록 서식에 맞춰 세부값 범주(신체 부위, 지원 유형 등)를 추가하고, 언어 추가도 동일한 구조로 확장합니다.
